# 📊 Netflix Data Analysis Dashboard using Python & Streamlit

## 📌 Project Overview

This project demonstrates a complete Data Analysis workflow using the Netflix Movies and TV Shows dataset. The main objective is to clean, analyze, visualize, and build an interactive dashboard to explore trends and insights related to Netflix content.
The project covers data preprocessing, exploratory data analysis (EDA), professional visualizations, and an interactive Streamlit dashboard for better user experience.

## 🎯 Objectives

* Perform data cleaning and preprocessing
* Analyze Netflix movies and TV shows dataset
* Generate meaningful insights from raw data
* Create professional visualizations using Python libraries
* Build an interactive Streamlit dashboard
* Understand real-world data analysis workflow

## 📂 Dataset Information

The dataset contains information about Netflix content, including:

* show_id
* type (Movie / TV Show)
* title
* director
* cast
* country
* date_added
* release_year
* rating
* duration
* listed_in (Genre)
* description

## 🧹 Data Cleaning & Preprocessing

The following preprocessing steps were performed:

* Removed duplicate records
* Handled missing/null values
* Filled missing categorical data logically
* Converted date columns into proper datetime format
* Created additional columns for year and month analysis
* Checked and cleaned inconsistent data types

## 📊 Exploratory Data Analysis (EDA)

Several analyses were performed to understand the dataset:

* Total Movies vs TV Shows
* Top Content Producing Countries
* Most Common Ratings
* Year-wise Content Addition Trends
* Genre Distribution Analysis
* Release Year Analysis
* Correlation Analysis using Heatmaps

## 📈 Data Visualizations

The project includes multiple visualizations such as:

* Heatmaps

Visualization libraries used:

* Matplotlib
* Seaborn

## 🖥️ Streamlit Dashboard Features

An interactive dashboard was developed using Streamlit containing:

* Dataset Preview
* Interactive Filters
* Summary Statistics
* Dynamic Charts
* User-Friendly Layout
* Real-time Data Exploration

Dashboard can be run using:

```bash
streamlit run app.py
```

## 📊 Key Insights

* Movies are more common than TV Shows on Netflix
* The United States contributes the highest amount of content
* Content addition increased rapidly after 2015
* TV-MA is one of the most common ratings
* Drama and International genres dominate the platform
