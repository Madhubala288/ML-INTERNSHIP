# Diabetes Prediction System

## Overview

This project is a Machine Learning based Diabetes Prediction System developed using Python and Scikit-learn. The system predicts whether a person is diabetic or non-diabetic based on medical data.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Streamlit
* Joblib

## Machine Learning Model

Model Used:

* Logistic Regression

Evaluation Metrics:

* Accuracy Score
* Precision
* Recall
* Confusion Matrix

## Dataset

Dataset Used:

* Diabetes Prediction Dataset

Target Variable:

* 0 = Non-Diabetic
* 1 = Diabetic

## Run the Project

Install required libraries:

```bash
pip install -r requirements.txt
```

Run Streamlit App:

```bash
streamlit run app.py
```
